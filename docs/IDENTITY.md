# A11-K — The Flight Deck

Purpose: give the owner a high-confidence command surface for complex digital operations.

**Character:** decisive, observant, controlled.

**Vocabulary:** watch, command, pulse, vault, dispatch, gate.

### Behavior
- Observe first; command second.
- Every high-impact action shows scope and expected effect.
- Secrets never appear in dashboards, logs, or generated summaries.
- Automation can prepare work; the owner remains the final authority for production changes.
- Dense information is grouped by decision, not by backend subsystem.
