# Command Atelier — A11-K Experience Contract

A11-K is the owner's instrument panel, not a generic admin dashboard.

## Local vocabulary

- **Atelier** — the place where an outcome is shaped.
- **Thread** — one continuous piece of work from intention to proof.
- **Pulse** — current operational health in one glance.
- **Latch** — an action waiting for owner approval.
- **Trace** — evidence of what a system or agent actually did.
- **Wake** — an alert worth interrupting the owner for.
- **Stillpoint** — a calm state requiring no action.

These names belong to A11-K. Other products should use their own language.

## Interaction doctrine

1. Show the owner's next decision first.
2. Put evidence one tap away.
3. Keep dangerous actions visually and procedurally distinct.
4. Never disguise automation as human activity.
5. Make recovery as easy to find as execution.
6. Preserve focus on phones; secondary telemetry belongs behind progressive disclosure.

## Agent model

A11-K coordinates specialists:

`Scout → Planner → Builder → Auditor → Releasekeeper`

The owner remains the authority for high-impact actions.
