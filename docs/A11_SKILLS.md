# A11 — Skills Register

Status: ACTIVE
Owner: CEO A.K. / Angel L. Krastev
Scope: A11-K public operating surface

## Core execution skills

1. Reality Verification — distinguish direct evidence, verified artifacts, and unverified claims.
2. Evidence Engineering — capture URL, commit, HTTP result, timestamp, changed files, outcome, next action.
3. Public Surface Engineering — improve pages, metadata, canonical, sitemap, accessibility, and discoverability.
4. Commercial Engineering — turn verified capability into a clear offer, proof path, CTA, and qualified opportunity.
5. Market Intelligence — identify high-value country/sector opportunities from public evidence.
6. Governance Engineering — translate operating principles into executable controls and evidence.
7. Reliability Engineering — test workflows repeatedly, detect failures, record recovery paths.
8. Security Engineering — minimum permissions, secret isolation, leak awareness, fail-closed operation.
9. Agent Orchestration — use specialised workers, bounded tasks, evidence checkpoints, and worker replacement when stuck.
10. Knowledge Engineering — convert verified findings into durable, searchable operating knowledge.
11. Editorial Engineering — create distinctive, premium, human-readable public material without generic AI styling.
12. Revenue Evidence — track offers, qualified opportunities, proposals, sales evidence, and outcomes without inventing traction.

## A11 signature capabilities

### Proof Graph
Claim -> source -> test -> artifact -> decision.

### Reality Index
Evidence x Security x Human Benefit x Deployability x Reversibility.

### Good Chaos Lab
Controlled testing of bad data, conflicting instructions, outages, malicious inputs, permission failures, hallucination traps, economic shocks, escalation, and recovery.

### Human Dividend
Measure time returned, decisions accelerated, errors prevented, work removed, accessibility, escalation quality, incidents avoided, and knowledge created.

### Decision Memory
Decision -> evidence -> action -> outcome -> lesson.

### Failure Genome
Failure -> pattern -> cause -> containment -> recovery -> prevention.

### Opportunity Radar
Verified market signal -> affected audience -> unmet need -> offer -> evidence -> qualified opportunity.

## Execution rule

Execute the smallest useful real change. Verify it. Record it. Move to the next highest-leverage reversible task.
