Activate it in six steps

The supplied Opportunity Radar material defines a GitHub Actions route and a webhook fallback for sending the resulting report. This page shows the workflow without pretending an endpoint or secret is already configured.

01

Enable trigger

Add or verify workflow_dispatch so an owner can start a run manually.

02

Protect delivery

Store the webhook URL/API token as a GitHub Actions secret, never in source.

03

Build report

Collect opportunities, score fit, attach evidence and produce the executive summary.

04

Send

POST the report to the configured delivery endpoint or use the documented fallback.

05

Verify

Check the workflow result, HTTP response, receipt and timestamp.

06

Record

Keep the run ID, delivery evidence and final status for the owner.

Current boundary: the supplied Opportunity Radar source describes the activation procedure and email destination, but it does not provide a live webhook URL or prove that the workflow has already delivered an email. Therefore this visual marks external delivery as UNVERIFIED until an actual run proves it.
